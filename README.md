A make.fun entry for **One Line, One Chill** (u-azazex-one-line-one-chill-6d4d5488).

`main.ts` writes a single horror sentence — under 200 characters, one sentence, no setup — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
